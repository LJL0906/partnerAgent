# 需求文档索引

本目录用于记录个人助手的需求和技术架构结果，当前处于详细子需求拆分阶段。

## 版本规则

- `v1`：第一期优先实现，用于验证核心闭环。
- `v1.1`：第一期核心闭环之后的输入和能力增强。
- `v2`：第一期暂不实现，但已确认方向或需要后续补充。
- 未标注版本：尚未完成版本归属，或属于跨版本原则。

## 当前文档

- [个人助手项目交接文档](./个人助手项目交接文档.md)：新会话或新 Agent 接手项目时的首要阅读文档，包含产品目标、v1 范围、默认决策和后续工作顺序。
- [v1 需求澄清记录：前二十一组及产品补充决策](./v1-需求澄清记录-前二十一组及产品补充决策.md)：记录截至 2026 年 9 月 3 日已经讨论的前二十一组需求，以及在进入技术架构前默认采用的产品决策建议。
- [v1 技术架构总览](./v1-技术架构总览.md)：记录已采纳的本地优先模块化单体架构、客户端与本地核心边界、数据流、模型、RAG、敏感信息和后台任务方案。
- [v1 原始记录与结构化存储](./v1-原始记录与结构化存储.md)：记录原始记录、聊天消息、附件、分析结果、候选项、正式对象、来源关系、删除规则和索引一致性。
- [v1 确认中心](./v1-确认中心.md)：记录确认卡片、候选和批次生命周期、确认命令、事务、幂等、风险提示、撤销和失败恢复规则。
- [v1 模型配置与调用](./v1-模型配置与调用.md)：记录模型配置、选择、推理等级、测试连接、调用链路、错误处理、重试切换和基础日志。
- [v1 敏感信息处理](./v1-敏感信息处理.md)：记录敏感类别、统一外发拦截、提醒/脱敏/阻止策略、敏感记忆和隐私确认边界。
- [v1 事实与长期记忆](./v1-事实与长期记忆.md)：记录事实来源与可信度、长期记忆确认、冲突更新、合并、删除、RAG 和决策经验边界。
- [v1 RAG 与处境模型](./v1-RAG与处境模型.md)：记录检索场景、状态过滤、依据展示、索引一致性、最小上下文和个人处境模型版本规则。
- [v1 行动状态机](./v1-行动状态机.md)：记录行动执行、计划、时效状态，确认转移、提醒联动、幂等和撤销规则。
- [v1 目标状态机](./v1-目标状态机.md)：记录目标状态、确认转移、行动松耦合、复盘联动、幂等和撤销规则。
- [v1 输入与内容提取](./v1-输入与内容提取.md)：记录文字、语音、附件提交、异步解析、输入分析、结构化提取和确认中心交接。
- [v1 行动摘要与提醒](./v1-行动摘要与提醒.md)：记录每日摘要、提醒、待确认提醒、周复盘、频率上限、后台补偿和确认交接。
- [v1 目标与决策辅助](./v1-目标与决策辅助.md)：记录下一步行动建议、目标冲突、决策记录、建议效果、高风险和确认交接。
- [v1 数据导出](./v1-数据导出.md)：记录 Markdown、JSON、原始文件包、来源和历史状态、敏感数据、保护、任务和迁移边界。
- [v1 详细子需求交叉整合](./v1-详细子需求交叉整合.md)：统一全局不变量、状态矩阵、端到端数据流、Local Core 逻辑接口和技术选型前置决策。
