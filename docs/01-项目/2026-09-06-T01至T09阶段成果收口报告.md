## 3. 统一契约与实现边界

- `@partner-agent/contracts` 是 `ChatOutputMode`、`ChatPreviewKind`、预览 JSON Schema、任务状态、ChatItem ID 与跨端 DTO 的唯一公开来源。
- 前端不再手写服务端状态/输出模式；后端工具 schema 与运行时 parser 消费同一共享定义；数据库枚举由共享类型派生。
- 预览只保存在 `session_messages.metadata_json.chat_previews`。没有新增 Action、Candidate、AnalysisRun 或预览业务表，也没有新增旧版 REST/WS 兼容旁路。
- 权威完成边界只接受 `chat + 0 preview` 或 `structured_preview/action + >=1 valid preview`。非法组合返回固定安全错误并由 runner 失败收口；严格写入拒绝非法集合，历史恢复则逐项隔离损坏、重复、数量/累计载荷超限项，并复制通过校验的值，避免调用方引用污染。
- ChatTask 第 23 条迁移新增持久正整数 revision；创建为 1，可见生命周期变化递增，纯 lease heartbeat 只续租，不改变 `updated_at` 或 revision。REST runtime 与 WS lifecycle 使用同一 revision。
- 正式业务数据仍只能经现有 `SubmitConfirmationBatch` 事务写入。本期没有调用或扩展该入口。
