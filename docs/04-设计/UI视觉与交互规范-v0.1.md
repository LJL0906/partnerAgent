# 紫灵 AI UI 规范（v0.1）

> 逐步补充，只记录已经确认的规则。
>
> 更新时间：2026 年 9 月 5 日

## 1. 公共 Token

颜色、透明度、状态色、渐变、字号、行高、间距、尺寸、最小触控区域、圆角、描边、阴影和动效等公共视觉参数，必须提取到：

```text
apps/partner-agent-frontend/src/theme/
```

组件和页面不得散落硬编码这些参数。新增视觉规则时，优先补充公共 Token，再使用 Token 实现组件。

这样后续切换浅色、深色或品牌主题时，只修改 Token，不逐个修改业务页面。

## 2. Toast 与浮层

当前产品使用浅色主题，因此 Toast 默认使用：

- 浅色表面；
- 深色文字；
- 语义色图标和描边；
- 轻量阴影。

不要为了追求“科技感”使用大面积深色背景、强辉光或高对比霓虹色。

成功、警告、错误和信息状态不能只靠颜色区分，还要配合图标或明确文字。

Toast 的颜色、描边、阴影和间距必须使用公共 Token，不在组件中直接写色值或视觉参数。

## 3. 后续维护

后续遇到新的视觉问题或形成新的共识时，逐条补充到本文档。未写入本文档的内容，不视为已经冻结的设计规则。


## 4. 第一版主题

第一版统一使用浅色主题。按钮、悬浮按钮、菜单和主要浮层不得使用大面积深色背景或白色文字作为默认样式；状态色只用于语义强调，具体颜色统一从公共 Token 获取。

## 5. 登录 / 注册页面 Token

登录和注册页面的布局、表单字段、主操作按钮和第三方登录按钮使用页面专用 Token：

```text
apps/partner-agent-frontend/src/theme/auth.ts
```

### 5.1 页面布局

登录/注册页面统一使用：

- 内容最大宽度：`authTokens.layout.maxWidth`；
- 页面区块间距：`authTokens.layout.sectionGap`；
- 表单字段组间距：`authTokens.layout.fieldGroupGap`；
- 操作区间距：`authTokens.layout.actionGroupGap`。

### 5.2 表单字段

输入框使用 `authTokens.field`：

- 最小高度；
- 水平和垂直内边距；
- 普通与聚焦边框颜色；
- 普通与聚焦边框宽度；
- 输入文字和占位文字颜色；
- 字段标签字距；
- 密码输入右侧操作按钮空间。

字段聚焦时只改变语义边框 Token，不在页面中写入临时色值。

### 5.3 登录 / 注册主按钮

主操作按钮使用 `authTokens.primaryAction`：

- 最小高度和宽度；
- 横向内边距；
- 胶囊圆角；
- 品牌描边和文字颜色；
- 浅色品牌背景；
- 禁用透明度；
- 按压透明度和缩放。

### 5.4 第三方登录按钮

QQ、微信等第三方登录入口使用 `authTokens.providerButton`：

- 统一触控尺寸；
- 浅色表面；
- 公共边框和圆角；
- 统一按压反馈。

第三方品牌色可以保留为语义 Token，不在页面中散落硬编码。
