# Partner Agent 文档中心

> 本目录统一收纳项目的产品需求、项目管理、技术草案与设计参考。
> 单一仓库，文档按主题归类；`需求/`、`docs/design/` 等旧路径已迁入此处。
> 最新权威状态以根目录 `README.md` 与 `docs/01-项目/开发交接说明.md` 为准。

## 目录结构

```text
docs/
├── README.md                  # 本文档：文档中心索引
├── 01-项目/                   # 项目管理：目录、交接、基线决策、阶段总结
│   ├── P0决策收口文档.md      # 业务基线（正式对象写入边界、状态机、信封、错误码）
│   ├── 开发交接说明.md        # 唯一交接说明：现状、验证、下一步
│   ├── 项目架构说明.md        # 仓库边界、目录职责、演进规则
│   └── 阶段0-4实施总结.md     # 阶段 0–4 实施记录
├── 02-需求/                   # 产品需求与技术选型（原 需求/）
│   ├── README.md              # 需求文档索引
│   ├── 个人助手项目交接文档.md # 产品侧交接与默认决策
│   └── v1-*.md                # v1 详细子需求、状态机、架构、选型
├── 03-技术草案/               # Pi 分析与 Local Core 实现草案
│   ├── Local Core REST与WS路由草案.md
│   ├── 数据库Schema草案.md
│   ├── pi-agent-分析文档.md
│   └── Pi-Agent-目录说明.md

    ├── 前端聊天主屏实现.png
    └── 前端聊天主屏设计参考.png
```

## 文档定位

| 目录 | 内容 | 代表文档 |
|---|---|---|
| `01-项目/` | 项目边界、当前阶段、交接与基线 | `开发交接说明.md` |
| `02-需求/` | 产品范围、状态机、服务边界、技术选型 | `v1-技术架构总览.md`、`v1-详细子需求交叉整合.md` |
| `03-技术草案/` | Local Core 路由/存储草案与 Pi 分析 | `Local Core REST与WS路由草案.md` |
| `04-设计/` | 前端视觉参考 | `前端聊天主屏设计参考.png` |

## 权威性

- **业务基线**：`docs/01-项目/P0决策收口文档.md`
- **当前阶段与交接**：`docs/01-项目/开发交接说明.md`
- **仓库边界与演进**：`docs/01-项目/项目架构说明.md`
- **产品规范**：`docs/02-需求/`，尤其 `v1-详细子需求交叉整合.md`（全局不变量）与 `v1-技术架构总览.md`

发现文档与上述基线冲突时，先指出冲突再给出最小纠正方案，不得静默覆盖。
