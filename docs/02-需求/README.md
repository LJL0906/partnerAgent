# 需求文档索引

本目录用于记录个人助手的需求、技术架构和技术选型结果。接口契约、数据库基础和通用 Agent 技术底座已经落地，P1-01「Action 分析契约与数据基础」已完成；业务当前暂停，按用户安排于 2026 年 9 月 6 日再进入 P1-02「Action 候选生产链」。当前状态以 [`开发交接说明`](../01-项目/开发交接说明.md) 为准。

## 版本规则

- `v1`：第一期优先实现，用于验证核心闭环。
- `v1.1`：第一期核心闭环之后的输入和能力增强。
- `v2`：第一期暂不实现，但已确认方向或需要后续补充。
- 未标注版本：尚未完成版本归属，或属于跨版本原则。
