# 结构化预览实际展示与恢复实施计划

> **执行说明：** 按当前任务授权直接实施；主 Agent 负责前端集成与收尾，只读子 Agent 负责后端链路和日志证据核验。

**目标：** 将 Agent 已持久化在聊天消息附件中的 `ChatPreviewV1` 作为真实、可恢复且不触发正式业务写入的行动预览展示出来。

**架构：** PostgreSQL/内存任务存储中的消息附件仍是预览真相源，任务完成事件只触发 REST 会话快照回读；前端按共享 `ChatItem` 的稳定 `preview:<preview_id>` 身份合并。独立 `StructuredPreviewCard` 只展示共享契约允许的公开字段，展开和复制均为本地交互，不复用候选确认或正式行动接口。

**技术栈：** Expo SDK 57、React Native、React 19、Zustand、Vitest、共享 TypeScript 契约。

**依据：** `docs/05-任务架构/2026-09-06-修复与联调任务分配.md` 的 T07。

## 全局约束

- 固定展示“未确认预览，未创建行动”。
- 首期仅展示 `kind: action`，非法 schema 不渲染成功卡。
- 来源引用只作为文字，不伪装正式对象详情链接。
- 复制内容只包含卡片已展示的安全公开字段。
- 不新增或调用正式确认、行动创建、候选批次接口。
- 不记录完整预览或草稿正文。
