# 前端数据与基础错误修复实施计划

> **执行范围：** T05 前端身份、数据状态、恢复和现有错误修复；T07 结构化预览展示不在本计划中，聊天相关文件完成后只做交接。

**目标：** 前端严格消费 T01 共享契约，修复账户切换残留、登录过期导航、设置页更新循环、构建错误，以及 REST/WS 交错恢复覆盖。

**架构：** `items` 是唯一可写展示集合，兼容消息仅从 items 只读投影。服务端 item 依稳定 `item_id` 和正整数 `revision` 合并；本地乐观输入使用显式本地身份，不伪造服务端 revision。会话 generation、账户 user.id 与请求 generation 共同隔离迟到回调。

**技术栈：** Expo 57、React Native 0.86、React 19、Zustand 5、TypeScript 6、Vitest 4。

## 全局约束

- 只修改 `apps/partner-agent-frontend`、本计划和最终 T07 交接文档；不修改共享契约和后端。
- 不覆盖当前工作树中其他任务的已有改动；不批量删除 memory、history fallback、旧协议或测试实现。
- 新增行为先用聚焦回归复现，再做最小实现；最后执行前端 test、build、lint 与真实 Web 页面验证。
- `ChatItem.revision > 0` 只表示服务端持久修订；本地乐观项使用不会通过契约解析的 `revision = 0` 显式哨兵，WS channel sequence 不得参与 item 合并。

## 任务 1：账户身份、切换清理与路由

**文件：** `src/features/auth/auth-store.ts`、`auth-store.spec.ts`、`src/app/_layout.tsx`、必要路由测试、`src/app/(tabs)/profile.tsx`。

- 保存完整 `AccountPublicUser`，校验 access token `sub` 与 `user.id` 一致。
- 当刷新结果从账户 A 变为 B，先执行已注册 teardown 并使 A 的旧请求失效，再发布 B 的 authenticated 状态。
- `expired`/`unauthenticated` 访问受保护路由时导航至 `/auth`；authenticated 从认证页返回 `/chat`。
- profile 使用稳定的原子 selector，避免 Zustand 5 对象快照循环。

## 任务 2：单一展示源与 REST/WS 修订合并

**文件：** `src/store/chat-store.ts`、`src/features/chat/chat-session-snapshot.ts`、`chat-event-routing.ts`、`chat-event-state.ts`、`chat-message-submission.ts`、`use-chat.ts`、`session-management.ts` 及对应 spec。

- 删除 messages 双写、正文前缀身份猜测和确认无生产调用的四个 store 方法；提供 items 到旧消息组件的纯只读投影。
- 将共享 `SessionMessageDto` 用 `chatItemIds` 和共享状态映射转换为恢复 item；不使用数组下标、时间或正文生成身份。
- 快照逐 item 合并：低/同 revision 去重；不存在于快照的本地或更晚实时 item 保留；切换会话仍通过 reset 隔离。
- text/thinking delta 仅在 `text_offset` 等于当前 UTF-16 正文长度且 revision 更新时追加；重复忽略，缺口请求 REST 恢复。
- 本地提交 catch 标记 transport unknown 并保留相同 operation/input 供对账/重试；只有 REST/WS 权威 task 终态写 failed/cancelled/completed，迟到成功可覆盖未知传输态。
- 所有异步回调在写 store 前校验当前 session generation、session ID、task/operation 身份。

## 任务 3：模型能力、运行态/工具态与链接

**文件：** `src/api/chat-api.ts`、`src/features/chat/components/chat-screen.tsx`、`chat-input.tsx`、`chat-message-list.tsx`、`message-bubble.tsx`、`messages/message-content.tsx`、必要卡片与 spec。

- `SubmitTextInputPayload` 和模型切换结果使用共享契约；模型默认推理等级取 `default_reasoning_level`，选项严格等于 `reasoning_levels`，不得自行补 `off`/`medium`。
- 模型切换只展示服务端返回的权威提示 item/message；迟到回调不得回滚或写入另一会话。
- waiting/cancelled、工具 pending/executing/indeterminate/undone、风险/过期/allowed_actions 按共享状态展示；ACK 只更新控制反馈，不冒充工具终态。
- Markdown 链接保留 URL 并可点击；仅打开 `http:`/`https:`，非法协议保持普通文本/不可打开。
- 移除 React Native 不支持的 table/row/cell accessibility role，保留可理解的 label。
