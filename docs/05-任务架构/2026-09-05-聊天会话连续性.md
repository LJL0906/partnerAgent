## 本批交付范围

- 后端提供 owner-scoped 会话列表；列表与详情附带活动/最近任务资源引用，客户端不推测任务归属。
- 列表包含标题、更新时间、最近消息预览；不返回 Pi 内部上下文。
- 聊天入口支持历史选择和新建；新建空白会话不提前订阅不存在的服务端资源。
- 客户端按服务地址和用户隔离保存选中会话引用；历史正文从 REST 读取，Web 登录令牌继续仅存内存。
- 会话切换、退出和重启恢复必须拦截旧异步结果，防止消息串线。
- 切回前台通过 REST 恢复任务/消息；Socket 断开或切换会话不取消服务端任务。
- 消息列表默认按内容增长持续贴底；用户主动滚动时暂停，再次触底或点击回到最新消息后恢复。发送消息不强制恢复；布局变化不误关跟随；底部采用 2px 舍入容差并计入留白和页脚。
- 导航收敛为助手与设置；保留既有业务占位文件但隐藏入口。

## 分工

- 后端 Agent：后端查询/存储、共享契约、相应测试。
- 会话运行时 Agent：前端 API、store、会话选择持久引用、恢复与异步隔离、相应测试。
- 主 Agent：会话列表与聊天 UI、路由/导航、文档、整合与验收。
- 审查 Agent：只读检查会话切换、注销及晚到结果风险。

## 验收

1. 两个会话切换，历史和续聊不串线。
2. 客户端重新打开后能找回已选择会话；Web 重新登录同一用户后能恢复引用。
3. 恢复活动任务时读取服务端权威状态，取消仍按 owner/task 生效。
4. 断网恢复与前后台切换不重复显示消息，不覆盖新选择。
5. 历史阅读不因回复增长被拉到底部。
6. 无新增业务对象写入、无迁移、无密钥与正文持久缓存。

## 边界

本批不包含完整登录/刷新令牌、Markdown、消息编辑/重新生成、全文历史分页、正式工具批准页面或结构化提案。既有最近 100 条消息保留策略继续有效，不宣称无限历史。手机上的系统杀进程、键盘与前后台行为需真机验收，浏览器与单测不能替代该项。

## Android 输入框聚焦布局修复（2026-09-05）

用户反馈 Android 真机 / Expo Go 聚焦输入框时持续闪烁。代码检查发现 Android 的 `KeyboardAvoidingView` height 补偿与系统 resize、键盘弹出时隐藏导航栏同时改变布局；这是待真机验证的风险定位，尚未独立复现根因。

本轮将键盘避让限制为 iOS padding，Android 交由系统 resize；输入框固定 2px 边框，只切换聚焦颜色；回到最新消息按钮改为悬浮，显示和隐藏不挤压列表；增加已在底部时跳过重复滚动的判断。保留用户滚动暂停、再次触底恢复的规则。处理方式参考 [Expo 键盘指南](https://docs.expo.dev/guides/keyboard-handling/)。

验证：滚动策略专项测试 10/10，前端 build、lint 通过。390×844 隔离 Web 验证中，聚焦前后输入框均为 72px 高且位置相同；暂停期间消息增长后滚动位置保持 1033.60，点击回到最新消息后底部距离约 0.20px，按钮隐藏前后列表可视高度均为 549px。Web 检查不代表 Android 原生键盘验证；仍需 Expo Go 重新加载后检查键盘弹出、收起和连续输入。
