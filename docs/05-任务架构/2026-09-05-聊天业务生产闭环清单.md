## 1. 已确认范围

本清单承接当前聊天消息列表闭环追踪文档中关于消息、运行态、候选提案和业务结果的分层要求。当前确认范围如下：

1. **聊天工作区**：当前聊天为多类型可折叠工作区，可承载普通消息、思考/推理状态、工具调用、候选提案、确认状态、运行状态及业务结果等不同类型内容。
2. **正文边界**：正文不折叠。折叠只适用于工作区中的辅助信息、运行态、思考/推理块、工具详情或其他非正文区域；不得为了视觉收纳而隐藏用户正在阅读的正文内容。
3. **业务展示边界**：业务内容当前只允许结构化预览与安全打印。预览用于说明候选内容、来源、风险、状态和待用户决定的事项；安全打印必须遵守现有敏感信息处理和脱敏规则。
4. **正式业务写入边界**：本阶段不新增、不调用正式业务入库 API，不绕过现有确认事务，不改变已有确认事务的行为、权限校验、幂等语义、冲突处理和生效规则。
5. **运行态持久化**：聊天运行态允许持久化，以支持刷新、重启、断线重连、会话切换和恢复；运行态持久化不等于正式业务对象已生效。
6. **状态真实性**：界面展示的预览、完成、确认、处理中或失败等状态，必须与实际服务端状态和可核查证据区分，不能把 UI 状态当作业务落库结果。

## 3. 真实闭环定义

行动提案只有在以下链路全部成立时，才可称为真实业务闭环：

```text
聊天输入 / Agent 产出
  → 可追溯的结构化行动提案
  → 安全结构化预览与打印
  → 用户明确决定（接受 / 修改后接受 / 拒绝 / 稍后处理）
  → 复用现有确认事务
  → 服务端权限、所有权、版本、幂等和状态校验
  → 正式业务写入
  → 查询接口回读正式对象
  → 聊天状态更新为可核查结果
  → 断线、重启、刷新后恢复且不重复、不串线
```

以下任一项缺失，都只能标记为“预览”“部分实现”“待验收”或“未实现”，不得标记为生产闭环：

- 只有卡片、开关、按钮或本地状态，没有服务端事务结果；
- 只有候选生成，没有用户决定记录；
- 只有用户决定，没有正式对象生效证据；
- 只有写入，没有查询回读；
- 只有当前页面显示，没有断线/重启恢复；
- 只有测试环境通过，没有生产配置、权限和真实依赖下的验收证据；
- 只有“成功”文案或布尔开关，没有可关联的请求、事务、对象和审计证据。

## 4. 后续真实闭环门槛

### 4.1 业务与状态门槛

- 明确行动提案与正式 Action/行动对象的边界；候选不等于正式对象。
- 明确状态机，至少区分：提案生成、预览、待用户决定、用户已接受/已修改接受/已拒绝/稍后处理、事务处理中、已生效、冲突、失败、过期。
- 聊天运行态、用户决定、确认事务状态和正式业务结果分别建模、分别展示、分别可恢复。
- 正文保持不折叠；辅助信息可以折叠，但折叠不得丢失状态、错误或来源证据。

### 4.2 安全与权限门槛

- 所有动作按 owner、session、task、operation 做边界校验。
- 权限不足、对象不存在、状态不允许、版本冲突和过期必须有可观测的失败结果。
- 结构化预览和安全打印不得泄露密码、API Key、令牌、身份证件、银行卡等敏感信息。
- 不允许客户端、模型、Pi、RAG 或聊天运行态直接写正式业务对象。

### 4.3 事务与一致性门槛

- 复用现有确认事务，不新造旁路入库 API，不改变既有确认事务行为。
- 用户决定具备命令级和业务级幂等，重复提交不能重复生效。
- 发生批次版本冲突、对象版本冲突或并发确认时，结果必须可区分且不得静默覆盖。
- 写入成功、查询回读成功、聊天状态更新和恢复提示之间要有可关联标识。

### 4.4 恢复与验收门槛

- 断线、刷新、重启、切换会话后，预览、用户决定、事务结果和业务结果可恢复。
- 事件重放不重复消息、不重复提交、不串 owner/session/task/operation。
- 至少覆盖正常、拒绝、重复、越权、冲突、过期、超时、服务端失败、数据库失败和恢复场景。
- 测试环境通过不得标记为生产已验收；必须明确环境、依赖、数据范围和未验证风险。

## 6. 三类状态必须分开交付

| 状态类别 | 含义 | 可否单独宣称业务闭环 |
|---|---|---:|
| **交付状态** | 代码、契约、测试、部署或文档是否完成 | 否 |
| **用户决定** | 用户对候选提案的接受、修改后接受、拒绝或稍后处理 | 否 |
| **业务结果** | 服务端确认事务与正式对象查询回读得到的实际结果 | 只有此项与前两项及恢复证据闭合时才可以 |

交付状态可以是“前端已展示”或“接口已接线”，用户决定可以是“已接受”，但这些都不能替代“正式对象已生效”的业务结果。业务结果必须来自服务端确认事务和正式查询回读，不得来自按钮状态、前端缓存、预览 JSON、测试桩或文案。
