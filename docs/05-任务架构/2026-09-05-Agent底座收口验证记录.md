## Outbox 收口

工具控制通知使用独立的 `tool_control_outbox`，状态变更与事件写入处于同一数据库事务。覆盖事件：

- `tool_confirmation_confirmed`
- `tool_confirmation_dismissed`
- `tool_execution_start`
- `tool_execution_end`
- `tool_undo_available`
- `tool_undo_completed`

Relay 使用稳定事件键、租约令牌、按会话头阻塞和有限重试，避免并发重复领取及同会话乱序。

毒性事件处置入口为本地运维命令 `npm run outbox:remediate --workspace @partner-agent/backend -- ...`。入口不开放 HTTP，依赖数据库连接权限；列表不返回事件载荷；`retry` 或 `discard` 必须同时提供事件类型、事件 UUID、预期尝试次数、操作人标识和精确确认短语。处置在事务内校验当前状态并写入 `outbox_remediation_audits`。最终镜像对隔离数据库实跑 `list --limit 10`，返回空列表。
