## 范围与身份边界

- 正式页面只提供用户名密码注册和登录，已移除 JWT 输入页面与入口。
- 用户名为 3–32 位英文字母、数字、下划线，去除首尾空格并转小写；密码为 12–128 个字符，不 trim、不截断。
- 注册生成独立 UUID 用户身份，复用 `users.id` 和 JWT `sub`；不修改、不合并历史开发账户及其聊天记录。
- 账户密码采用 Node 内置 scrypt 加随机盐，参数 `N=32768,r=8,p=3`，不保存明文密码。参数依据 [OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。
- 访问 JWT 有效期最长 15 分钟，刷新会话有效期 7 天（绝对期限，不滑动延期）。数据库只保存刷新令牌 SHA-256 摘要；刷新使用数据库原子比较与替换，旧令牌不能再次刷新。
- 退出撤销当前登录会话；原访问 JWT 和刷新凭据随即失效。同一实例的正式 WS 连接在退出或访问 JWT 到期时关闭，客户端使用新访问令牌重连。
- 账户异常只返回固定安全提示，数据库异常不透传查询参数、密码哈希或刷新摘要。

## API

账户接口独立于 Local Core Command 信封，共享 DTO 位于 `packages/contracts/src/账户.ts`；不得向 Model Gateway 传递账户密码。

| 请求 | 输入 | 成功结果 |
| --- | --- | --- |
| `POST /api/v1/auth/register` | `{ username, password }` | 201，登录结果 |
| `POST /api/v1/auth/login` | `{ username, password }` | 200，登录结果 |
| `POST /api/v1/auth/refresh` | Native：`{ refresh_token }`；Web：空对象与 Cookie | 200，轮换后的登录结果 |
| `POST /api/v1/auth/logout` | Native：`{ refresh_token }`；Web：空对象与 Cookie | 204，撤销当前登录会话 |
| `GET /api/v1/auth/me` | Bearer access JWT | `{ id, username }` |

登录结果含 `access_token`、`expires_at`、`refresh_expires_at`、`user: { id, username }`；时间戳单位毫秒。Native 另返回 `refresh_token`，Web 不在 JSON 中返回刷新凭据。

用户名冲突为 409；错误密码和不存在账户统一为 401；输入错误为 400；限速为 429；未知账户存储异常为安全的 503。

## 客户端与部署

- HTTP 与 Socket.IO 共用 token provider，临近过期时合并并发刷新请求。HTTP 401 不自动重放业务写请求；旧 token 的迟到 401 不清除已更新的登录状态。
- Native 刷新凭据保存在 SecureStore，键按服务地址隔离。Web 访问令牌仅内存保存，刷新凭据使用 `HttpOnly; SameSite=Strict; Path=/api/v1/auth` Cookie，生产环境附加 `Secure`。
- Web 请求携带 `X-Auth-Client: web` 和 credentials；Cookie 相关请求必须有明确白名单 Origin。不要将前端放在 localhost、后端放在 LAN IP 形成跨站配置；Web 应使用同站地址，生产通过 HTTPS 部署。
- 注册/登录按源 IP 限速；登录另按 IP+用户名限速；密码计算最多并发 4 次。限速器是有上限的进程内存实现，适用于当前个人单实例；多实例部署需独立评审共享限速及跨实例会话撤销通知。
- 退出先清除内存访问权和聊天资源；退出完成前阻止新登录与刷新互相覆盖。网络导致远端退出失败时显示可重试状态，不宣称撤销成功。
- 正式前端不再提供开发 JWT 入口。原签发 CLI 与测试辅助函数保留用于工程验证。
- 本次不包含找回密码、修改密码、邮箱/手机验证码、MFA 或历史开发身份绑定。
